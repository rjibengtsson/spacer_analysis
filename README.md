# Spacer sequence analysis

This repository contains all the projects for Cas13b spacer sequence analysis.

## Overview

Exploring molecular signatures within Cas13b spacer sequences that underlie functional potency, derived from bacterial genomic data.

## Subprojects

| Folder | Description | Status |
|---|---|---|
| `abacbs2025/` | abacbs 2025 conference presentation | Complete |
| `atlas_summary/` | CRIPSR-Cas Atlas Cas13b spacer sequence analysis | Active |
| `modules/` | functions used across this project | - |
| 


See each subfolder's own README for setup and how to reproduce that analysis.
