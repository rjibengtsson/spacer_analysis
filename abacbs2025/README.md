# ABACBS 2025

Code and data for figures and analysis presented at the ABACBS 2025 conference poster.

## Overview

This folder contains analysis of Cas13b (Type VI-B) CRISPR systems from the CRISPR-Cas Atlas, focused on characterising spacer sequences and identifying their phage targets via BLASTN.

## Contents

- **`abacbs_poster.ipynb`** — Main notebook for generating figures and summary tables for the poster.
- **`scripts/`** — Supporting scripts for running spacer BLASTN searches (`spacer_blastn.py`), processing BLAST metadata (`generate_blastn_meta.py`), and compiling results (`compile_results.py`).
- **`figs/`** — Output figures generated from the notebook.
